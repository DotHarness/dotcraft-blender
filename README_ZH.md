# DotCraft Blender

[English](./README.md) · [DotCraft](https://github.com/DotHarness/dotcraft) · [Blender](https://www.blender.org/)

面向 Blender 的 Agent 集成：直接操控运行中的会话，无需安装任何加载项。

</div>

## 你可以用它做什么

| 工作流 | 适用场景 |
|--------|----------|
| 检查场景 | 想知道一个文件里有什么：对象、网格、材质、修改器 |
| 建模与编辑 | 想让它替你创建或修改几何体、材质和节点 |
| 查看结果 | 想在改动前后看一眼视口 |
| 渲染 | 想渲染一帧，而且不希望渲染期间会话被冻住 |

## 安装

打开 **Plugins**，找到并安装 **Blender**。安装完成后，点击 **Try in chat** 即可开始使用。

![DotCraft 中的 Blender 插件](https://github.com/DotHarness/resources/raw/master/dotcraft-blender/dotcraft-blender-plugin.png)

## 快速开始

描述你想要场景变成什么样。如果 Blender 还没运行，DotCraft 会替你打开，做出改动，然后把结果给你看。

> 打开 `kitchen.blend`，在台面上方加三个细分球排成一行，各用不同颜色的材质，然后给我看看效果。
