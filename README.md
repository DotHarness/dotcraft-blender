# DotCraft Blender

[中文](./README_ZH.md) · [DotCraft](https://github.com/DotHarness/dotcraft) · [Blender](https://www.blender.org/)

AI agent integration for Blender—drive a live session, with no add-on to install.

</div>

## What you can do

| Workflow | Use this when |
|----------|---------------|
| Inspect a scene | You want to know what is in a file: objects, meshes, materials, modifiers |
| Build and edit | You want geometry, materials or nodes created or changed for you |
| See the result | You want to look at the viewport before and after a change |
| Render | You want a rendered frame without the session freezing while it runs |

## Install

Open **Plugins**, then find and install **Blender**. Once installed, select **Try in chat** to start using it.

![Blender plugin in DotCraft](https://github.com/DotHarness/resources/raw/master/dotcraft-blender/dotcraft-blender-plugin.png)

## Quick start

Describe what you want in the scene you are working on. DotCraft opens Blender if it is not already running, makes the change, and shows you the result.

> Open `kitchen.blend`, add three subdivided spheres in a row above the counter with different coloured materials, and show me how it looks.
